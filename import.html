Import Novel from AI
Paste or upload the combined JSON output from your AI session. The JSON contains both extraction data and analysis in one file.
  1. Download the files below — grab the AI Instruction Prompt and the JSON Schema. These tell the AI exactly what format to output.
  2. Open any AI (Claude is recommended) and open a project paste the instruction.txt as the project instuction.
  3. Attach the combined_schema.json file in the project so the AI knows the exact data structure.
  4. Paste your novel text (or upload as a file) into the conversation. The AI will extract all characters, locations, factions, etc. and produce a single combined JSON.
  5. Copy the JSON output (or download the .json file the AI gives you) and come back here to import it.
